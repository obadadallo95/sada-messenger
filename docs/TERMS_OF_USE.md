## 2. 📱 وصف الخدمة / Service Description

### 📱 **ما يقدمه صدى / What Sada Provides**
- مراسلة فورية بدون إنترنت
- تشفير شامل للرسائل (E2E)
- مجموعات محادثة مع إدارة أدوار
- إعادة إرسال ورد وتعديل الرسائل
- شبكة Mesh للاتصال في المناطق النائية

### ⚠️ **قيود / Limitations**
- يتطلب قرباً مادياً للأجهزة الأخرى (Bluetooth/Wi-Fi range)
- سرعة النقل محدودة (512KB max per message)
- الرسائل تنتقل عبر أجهزة وسيطة (relays) إن لزم الأمر
- لا ضمان بتوصيل 100% (offline-first nature)
